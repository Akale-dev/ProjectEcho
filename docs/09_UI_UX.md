# 09｜界面与交互规格

2026-09-30实施：主窗口已按录音、会议库、导出音频、转写与搜索、诊断与设置拆分；来源/mic与录音操作常驻。提供明暗主题、原创多尺寸图标；截图渲染与状态断言的具体证据见46。真实多显示器DPI切换、屏幕阅读器与Windows高对比仍须单独验收，不以高倍率PNG代替。

## 风格
简洁中文 Windows 桌面工具，关键技术名保留英文；优先可读性，不做复杂图形。支持100%/150%/200%DPI、键盘操作、浅色/深色、高对比。录音颜色之外还要文本状态，不能只靠红点。

## M2 最少入口
录音页：首页突出实际会议来源、录制范围、mic 独立开关、两路电平、计时、开始/暂停/停止和一个“标记此刻”。默认“未分类”与日期时间会议名，可录后修改/归档；不要求开会前填写项目资料。进程树/PID 放在来源详细信息，内部仍须验证实际音频会话与进程身份。
会议列表/详情：按日期列出已保存录音与恢复提示，可筛选项目、改名和归档。主要动作只有“播放完整录音”和“导出供转写”，显示各自生成/失败状态；源轨回放在详情中保留以便诊断。M3/M4 再添加文本检索、修订、决策/任务等界面，不提前展示空分析面板或假内容。

状态区分别显示捕获连接、最近保存时间、电平/是否观察到声音及磁盘余量。有效静音、尚未观察到声音和明确故障不混成同一个成功状态；单凭安静不自动停录或扩大范围。

## 预检
每场开始前在同一页明确显示并确认实际来源/采集范围、mic 开关与所选设备、输出目录和空间；详情可查应用/浏览器进程树。按实际原始采样格式估算占用，并预留混音/导出临时空间，不能按上传码率预算磁盘。
提供用户主动触发的 10 秒试录，首次使用/来源变化时突出提醒；不强制每场试录或重复完整向导。试录先停止 capture 并收尾再回放，真实会议中不自动播放测试音。录音期间（含暂停）禁用所有本程序回放；启动录音前先停止已有回放。
首次开启 mic 需醒目提示“与 Zoom/Webex 静音独立”；每场默认不录 mic，用户明确开启后本场保持状态。已验证来源偏好可保存，但每场重新解析并展示实际来源，不复用旧 PID、不悄悄更换失效麦克风。默认推荐耳机，独立麦克风不等于会议软件处理过的声音。

## 状态机
Idle → Preflight → Armed → Recording ↔ Paused → Stopping → Saved。
Recording可能进入Degraded（源丢失）或StoppingWithError（存储错误）；重开可显示Recoverable → Recovering → SavedWithGaps。
导出状态独立：NotQueued / Queued / Rendering / Encoding / Validating / Complete / Failed / Cancelled。
ASR状态也独立：NotConfigured / Ready / Running / Failed / Done / Cancelled。
点击Stop幂等，停止采集不等于导出完成。新录音与旧导出可并行，但导出资源限流优先录音。
Stop/Pause/MicOff 在对应边界确认前显示“正在停止并保存/正在暂停/正在关闭麦克风”；已保存以尾帧写盘和收尾结果为准，mic 已关闭以采集实际停止为准。暂停保持完整会话时间轴，首版回听/上传副本中该区间为静音，并可查看暂停记录。

## 关闭与托盘
正常关闭录音窗口必须询问“停止并保存”或“最小化到托盘继续”；不得静默后台录制。UI异常退出由capture host失联策略安全停止。托盘文案标明录音源与mic状态；快捷键可配置且冲突有提示。

## 导出页
默认按预设导出完整混音的分段副本；高级设置才展开已验证格式、最大字节/时长和重叠秒数。WAV + 一种已验证压缩格式为必需，M4A 是默认候选，第二种压缩格式可选。显示预计大小与最终实际大小，展示将导出的文件清单、完整时间覆盖及重叠信息；可显式选择通用提示词副本。
提供停止录音后的上传副本试播、打开目录；完成状态以解码/时长/大小校验结果为准。只包含明确所选派生文件，不默认打包原始轨、浏览器 profile、其他会议或项目。首版没有自动上传、范围剪辑、删除暂停、静音寻切点、音量/响度编辑器、来源诊断 stereo、术语管理或敏感区间编辑入口；这些延后功能不影响现有导出范围保护。
