# M3L Lite：精简字幕校订与启动刷新

日期：2026-10-06。继承实际交付的M3K-TimeFix-Final，只改Lite；旧版本、原始数据与Pro保留。用户本次要求：删去截图圈出的校订说明/状态区；释放空间给字幕列表；时间编辑显示两位小数；搜索框单行高度；启动自动刷新会议库；版本改为M3L。

## 最终行为

- 删除字幕列表下的时间/approximate/说话人说明行、固定格式说明、版本/音频时长及解析说明、未保存草稿说明行。字幕校订标签不再显示底部状态框或取消按钮，也不保留其空白高度；本地ASR标签的运行进度及取消功能保留。
- 时间仍在原118DIP窄框内，用固定冒号和小数点，显示`HH:mm:ss.ff`。百分秒栏两位，1表示0.01秒。
- 仅显示字幕或修改文字时，不修改原始毫秒时间。例如原123ms显示`.12`，仅改文字后仍保存123ms；用户实际编辑该边界时按10ms步进保存，另一边界保持原值。显示截取到百分秒，不把末端进位到录音之外。
- 常驻说明转到悬浮提示。非法时间仍有字段红框/悬浮原因；明确保存、导出、搜索或读取操作失败时提示，不用常驻状态框占空间。未保存关闭提醒与批量一次保存行为保留。
- 搜索输入框和搜索按钮都为32DIP单行高度。实际1280×887窗口下三语字幕列表高度261DIP，时间框仍118DIP；小窗口允许正常滚动。
- 启动在后台读取上次数据目录的会议元数据并更新左侧会议库，不自动选择会议、不播放音频。目录不可用时保留原路径，不建立替代目录。关闭或明确换目录/刷新会使旧启动结果失效，防止迟到结果覆盖新目录。
