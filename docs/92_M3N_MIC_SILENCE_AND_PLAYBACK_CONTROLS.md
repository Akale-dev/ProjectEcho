# M3N Lite：麦克风无声结束、播放图标与快捷键

日期：2026-10-06；基线为实际交付 M3M Lite。本次只维护 Lite，Pro 与旧包保留。包含用户后续追加的方向键快捷操作，以及录音中启用/取消自动结束。用户确认四个按钮顺序为 **−10、−5、+5、+10 秒**。

## 最终行为

- 自动结束仍是可选项，默认关闭、5 分钟，阈值可选 1/5/10 分钟。启用后远端与已开启的麦克风都没有有效声音，持续达到所选时间才因无声结束；所选根进程退出规则保留。
- M3M 的麦克风判断直接使用 >0.0001（约 −80 dBFS）峰值，极小的底噪也不断重置计时。本次合成测试复现了这一机制；没有采集用户麦克风，不能声称已测得用户设备的实际噪声。
- 麦克风改用每声道 10ms 窗口去直流后的 RMS，阈值 −50 dBFS；至少 1ms 的已发生前缀可参与判定。各声道独立，避免反相信号相互抵消；不同包大小和暂停/设备段不改变基本含义。低底噪和直流偏移不延长无声计时，达到阈值的声音继续重置。远端/应用的原判断保留。
- 检测只读取已经获得的合法 PCM，不开启额外麦克风、不改原轨、不降噪、不做 VAD/ASR，不删除末尾无声时间。收到包与观察到声音分开；缺包、不完整或故障不升级为完整静音。比阈值更低的实际弱声可能不重置计时，更强的背景噪声仍可能重置，真实设备需用户验收。
- **录音中和暂停时可启用、取消自动结束，也可调整时长**。设置请求在 CaptureHost 采集线程生效并回执，界面等待确认再显示新状态；等待请求期间暂时禁改。启用或修改时长后重新计时，暂停仍不计，恢复后给完整间隔。已进入停止/保存时不能取消收尾。
- 每次设置变化追加 `auto_stop_settings` 事件并保留新选项；初始 `selection.json` 仍记录启动时选择，另记 M3N 麦克风判定版本、方法和阈值；最终结束原因/分钟数与实际生效设置一致。旧调用缺少新字段仍默认关闭。
- 回听栏“停止”和倍速之间新增 −10、−5、+5、+10 秒按钮。自绘 WPF 矢量圆弧箭头参考用户示意，负值箭头向左、正值向右，数字不镜像。跳转限制在有效音频范围内，同时更新进度、时码与字幕；保留播放/暂停和倍速。
- 回听页 **↑/↓** 切换选中字幕，播放中从新选字幕开始；暂停时只换选中项。**←/→** 分别 −5/+5 秒，暂停时只改时间，播放时跳转并继续。下拉框、文本输入等控件保留原方向键操作；无有效时码的字幕不编造回放位置。
- 回听与字幕播放/校订的“从头播放”图标统一为**左竖线＋向右三角形**，与普通继续播放三角形不同。播放按钮专用样式固定安全内边距，焦点边框作为覆盖层，不挤压内容；正常、焦点和按下状态保持完整图标。
