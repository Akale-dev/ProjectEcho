## 已实现

### MP3与M2复审

导出界面现在提供M4A、WAV、MP3。MP3使用Windows Media Foundation，固定48kHz/96kbps mono，每次编码用合成信号核对本机延迟，再逐MPEG帧扫描、解码到EOF、校验实际字节/时长/真峰值。保留首尾与重叠，取消/失败只清理此次派生文件，原件不改。AAC路径补了本地路径/重解析检查与整个编码期间的源文件只读锁，AAC编码逻辑保持原合同。

实机发现MP3 sink对短文件自动生成的iTunSMPB补齐字段可能下溢。现去除该sink自动生成的ID3标签，保留MPEG音频帧，在清单登记673帧开头延迟与尾补齐。每个目标机每次编码均校准，不符就失败保留WAV。其他解码器/外部转写服务仍只是近似时间映射。

### M3

支持TXT/MD/SRT/VTT/ProjectEcho v1/v2 JSON导入，受限大小和严格时间/结构校验；原稿、规范化版本、人工修订分别保存。TXT/MD不造时间，用户提供的定时字幕一律approximate。实际M2帧映射通过当前混音SHA-256核对会议归属，拒绝跨无映射区间或二次映射。重叠只列候选、不删文字；人物标签不自动映射到真人。

界面可选择版本、搜索本场/当前数据目录会议、修改单段文字保存新修订，并从定时段定位完整混音回听。原稿和父版保留。搜索在本地按需读取文件，界面最多500场/2000条结果，没有SQLite。录音/暂停/保存收尾时，文字回听和原回放入口都禁用。

可选whisper.cpp配置保存于数据目录的settings；用户自行选择可信CLI与模型、确认来源/许可，可填写预期模型哈希。后台校验文件，生成保留完整时间轴的16kHz mono PCM16副本，再启动独立CPU进程。进程可取消/重试，原始输出、哈希、退出码与耗时独立保存，尝试低优先级。全数字零PCM不调用模型、不造文字。没有模型时录音/导出/导入仍可用，UI开始下一场不被旧文字任务锁住。

完整合同及限制见 [45](45_M3_TRANSCRIPTION_CONTRACT.md)。本版仅支持文字修订，暂不编辑时间戳/人物标签；不增加M4分析、自动上传或外部行动。

### 界面与图标

主窗口拆成录音、会议库、导出音频、转写与搜索、诊断与设置。顶部来源/mic状态和底部录音控制常驻；转写另分导入、搜索校订和本地识别三个子页。统一浅/深色主题，最低900×640，启动尺寸按可用工作区约束；正文滚动可达。

图标为原创青绿底、白色声柱、薄荷回声弧和珊瑚色录音点，包含16/24/32/48/64/128/256七尺寸，已嵌入PE图标和WPF窗口；SVG源稿与生成脚本可再生。详见 `src/ProjectEcho.App/Assets/README.md`。未使用外部图片素材。
