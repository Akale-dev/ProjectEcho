# 76｜同场说话人使用说明

M5 是会后本地声音分组。A/B/C 只表示本场声音的聚类结果，不是参会者姓名，也不等于远端轨或麦克风轨。自动结果可能误合、拆人或漏掉短插话，须结合回听判断。

M5B新增：回听列表/当前字幕显示人物标签；人物页单击或Enter即可回听；人物版本也可在“字幕回放与校订”编辑正文并另存。模型配置可明确选择TitaNet-Large、旧ERes2Net或自选文件，原有配置不会自动切换。具体对照结果和限制见[80](80_M5B_REPLAY_EDITING_AND_VOICE_QUALITY.md)。

M5C修复已知人数全场聚类：使用新包中的说话程序，TitaNet-Large与已知人数2可保持。点击“按说话人分段”另存新分析，不要只应用旧错误分析。另增显式手填换人时间与文字切点，即使模型漏检换人也能人工纠正；没有的正文须先人工补正，不能凭声音标签造字。详见[81](81_M5C_GLOBAL_CLUSTERING_FIX.md)。

## 分析已有字幕

1. 打开已保存的会议，准备完整混音，在“转写与字幕”选择需要标记的原稿或文字修订。
2. 打开“同场说话人”，核对“本地 CPU 模型配置”的程序、分段模型和声音特征模型及许可。缺模型时普通录音、回听和导出仍可使用；不会自动下载。
3. “已知人数”留空代表自动估计；填入人数后会生成另一份分析。人数是辅助配置，不是正确性保证。
4. 点击“按说话人分段”。完成后选择新的带说话人版本；旧原稿和人工修订继续保留。

同一混音已经分析过时，也可以选择“已保存声音分析”，点击“应用已保存分析”，把它应用到当前选定的原稿或文字修订。此操作不重新运行人物模型；声音哈希和时间线不符时拒绝应用。修改后的文字仍须通过自身音文映射检查，不能靠旧词界猜切点。

本机实测中，公开四人样本在产品准备音频后自动分成五组，叠声也有拆人失败。已知人数提示可以重试，但不保证正确。相似音色、同人跨语言及自然长会尚未验证；请使用显示改名和人工纠正核对结果。

处理完整已保存音频，使用其自身时间线：新录音去掉暂停，旧录音保留旧暂停，导入音频按文件时间。分析不重新删静音或加回暂停。开始下一场录音会取消后台说话人分析；暂停和保存期间不会播放本程序音频或启动说话人分析。

## 更正人物

- **显示名称：**选择人物，输入自己确认的名称，点击“保存显示名称”。名称仅在本场当前修订显示，内部人物 ID 不变。
- **单段改人：**选中字幕段，选择目标人物，点击“改这段的说话人”。证据不足可选择待确认。
- **合并：**将上方所选人物合并到目标人物，所有相关段落改为目标人物的引用，正文保持。
- **拆出：**选中被误归组的一段，点击“将这段拆出为新人物”，再给新人物改名；不会改变其他同组段落。
- **句内切点：**出现多人/待确认时先回听，选择模型给出的候选换人时间，在完整文字的正确分界放置光标，并选择左右人物。点击“在光标处分成两段”保存新修订。没有可靠音文边界时不会按文字长度分配时间，也不会生成重叠讲话的另一份文字。

每次更正都产生新版本。重跑分析不覆盖此前名称或修正；新聚类不保证与旧版同字母对应，选回原修订即可继续使用已确认结果。M5B可以直接校订人物版正文；新稿保留回听时间和人物引用，但改变的文字不会自动继承旧词界。新版人物校订稿请继续用M5B打开。再次运行声音分析或应用分析会从所引用的转写原稿另建人物版，已有正文校订版继续保留，可切回继续使用。

## 导出与保存

回到“校订与导出”，选定版本；“导出包含说话人标签”开启时，TXT/SRT/VTT 会添加当前显示名称的前缀，关闭时只输出正文。原字幕文字不写入标签。无时间 TXT/MD 不会凭空变成同步字幕。

复制可读字幕到其他工具不会带走本地稳定身份与修订关系；再次导入 `[姓名]` 前缀只是普通文本。请保留会议数据目录内的原音频、转写和 `diarization` 文件夹。SQLite 可以重建，权威 JSON 不应手动编辑。

所有处理和导出均在本地。本功能不上传、不建立跨会身份库、不自动采集麦克风。真实验证范围和未测项目见 [实施报告](75_M5_MEETING_SPEAKERS.md)。
