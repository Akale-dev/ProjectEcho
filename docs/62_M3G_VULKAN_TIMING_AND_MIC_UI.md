# 62｜M3G：Vulkan选择、百分秒时间与麦克风界面

2026-10-02。本轮基于 M3F，执行用户要求的五项修复与界面调整；保留此前原件、录音线程边界和现场验收限制。

## 实现

1. **随包 Vulkan**：完整包一直包含独立 CPU 和 Vulkan 两个程序，但 M3F 默认 CPU 路径不会随硬件下拉框切换。M3G 在所选程序属于当前包的两条已知路径时，联动选择对应 CPU/Vulkan 程序，界面显示真实路径并记入本地 Log；已有“随包CPU路径＋Vulkan”配置加载时在内存修正，只有主动保存才写回。相对路径仍可搬家。包外自定义程序、Auto/CUDA 不自动替换；缺失程序明确失败。GPU实际后端校验保留，不能把CPU回退记为Vulkan成功。
2. **0.01秒**：字幕/搜索行、选中字幕详情、两处回放时码及录音控制事件的生效时间统一显示 `HH:mm:ss.ff`。回放键盘细调为0.01秒。控制回执即使已有“已标记此刻”等文字，也附实际采集线程的生效时间，不用界面收到消息的时间代替。Log墙钟原有毫秒继续保留；字幕原毫秒、采集原微秒、SRT/VTT毫秒不改写。超过24小时的格式不回绕。
3. **录制模式**：中文为“从特定应用录音”和“从所有应用录音”，繁体与英文同步。后者仍只录用户明确选择的输出设备；前者仍为整个进程树，浏览器不代表单标签页。选项改名不改变捕获边界，不提供静默全系统回退。
4. **麦克风**：删除“本场明确开启麦克风”勾选项，将开关移至设备下拉框下方，使用透明背景原生矢量麦克风，关闭时有禁止标志，下方为“本机Mic录音”。默认关闭；单选设备不会开启。录音前点击只设置本场请求，显示“已开启·开始录音时采集”；录音中点击须等待实际ACK。关麦尚未确认时保留开启图案与等待文字，过期回执/health不会冒充停采成功。未选设备点击显示红框；设备关闭时不将预选设备固定给Host，首次实际开启后本场设备固定，不自动更换。录音中锁定来源字段但保留麦克风操作，暂停不能新开mic，停止保存中不能操作。新会议清除同意状态。
5. **删除试录**：移除新会议页10秒试录和试录试听控件、点击入口及相应新手提示。若需要短录，用户主动开始普通录音后自行停止；开发用历史M0采集验证代码不作为用户功能入口。

## 时间精度与准确性的区别

原数据没有被按整秒存储，旧界面隐藏了小数。新增百分秒也不会把模型本来估计偏移的语音边界变成10ms准确的声学对齐。本轮不加入新模型、强制对齐器、裁音或时间偏移猜测；旧稿不重写。字幕跟随仍依据实际原生媒体时钟，该时钟的播放更新频率可能低于100Hz。只有明确定位操作按所选毫秒定位。
