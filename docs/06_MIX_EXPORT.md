# 06｜音轨合并、保存与外部上传导出

## 核心定义
“合并”默认指把时间对齐后的远端和本地麦克风**混成同一个可听音频流**。不是两个文件塞进ZIP，不是先播远端再播mic，也不是容器里放两条默认播放器只播其中一条的独立音轨。[S10]
停止并完成原始块收尾后默认排队生成完整混音 `mixed_full.<已验证的默认格式>`；M4A 是默认候选，最终由可分发且通过验证的编码器决定，也可选择 MP3。合并/编码失败只标记导出失败，保留原始轨并允许停止录音后回放/重试。生成完成前别显示“合并已保存”。

## 同时保留的内容
源 remote + 已明确启用的 mic 独立块与时间索引；完整混音；用户选中导出的派生文件。每个 output 有 source hashes、render 版本、滤镜参数、时间映射和有效性检查。诊断 stereo 可用于开发验证，不进入 M2 普通用户界面，也不是默认上传文件。

## 渲染顺序
校验 manifest/源文件 → 重建来源时间轴 → 暂停/缺口保留时长并补静音（缺口原因保留）→ 多格式/采样率统一 → 依据时钟映射纠正偏移/漂移 → 固定并记录的增益/headroom → 真正混音 → 峰值保护 → 按目标编码 → decode probe/检查完整时长 → atomic finalize。
用 FFmpeg amix 可做混音、amerge用于通道组合，两者不可混淆；amix 的输入归一化/退出转场可能影响音量。不要默认 `-shortest`，避免较短轨使长轨尾段丢失。单靠 amix/aresample 无法推断丢失的原始时钟信息。[S10]
建议内部 float 渲染；默认留 headroom，最终真峰值目标 ≤-1dBTP（实测）。M2 不做来源音量/响度编辑器；后续响度处理只能生成派生文件，不能把静音段强行放大。限幅器延迟/编码 priming 须补偿/登记。归档原始轨保持不变。

## 导出预设（设计值，不是平台通用要求）
| 名称 | 格式 | 内容 | 建议参数 |
|---|---|---|---|
| 日常回听 | 已验证的默认压缩格式（M4A 候选，或 MP3） | true mono mix | 48kHz，96kbps，完整长度 |
| 导出供转写 | 同一默认压缩格式 | true mono mix | 32kHz，64kbps，默认可分段；用户核对接收方支持 |
| 无损交换 | WAV PCM16 | true mix | 48kHz，文件可能很大 |

M2 必须有可解码混音 WAV + 至少一种经过完整时长/大小/解码验证的默认压缩格式（MP3 或 M4A）。第二种压缩格式可低成本追加，但不作为 M2 闸门；未验证/缺 codec 的格式应不可选并说明，不得假装输出成功。FFmpeg/ffprobe 如随包分发，须记录来源、构建配置、哈希、许可证；不随意下载不明 exe。[S10,S11]

64kbps 音频有效载荷约28.8MB/小时、30分钟约14.4MB（decimal，忽略容器）；96kbps约43.2MB/小时。这是码率算式，不是实际大小保证。WAV 48kHz PCM16 mono约345.6MB/小时。

## 按大小/时长分段
默认“导出供转写”使用预设；高级设置提供 `maxFileBytes`（默认 20,000,000 为保守导出预算，不代表服务上限）、`maxDurationSeconds`（默认 1800）、`overlapSeconds`（默认 5，允许 0）及已验证格式。可由用户按接收服务修改。首版直接按确定性时间/字节预算切分，不实现静音寻切点。
切分以连续全混音时间轴为基准；每段独立从PCM编码并可独立解码，不依赖前一段头信息。先估算码率预算留5%余量，再实际编码测字节；超限缩短重试，有限重试后明确失败。VBR/AAC/M4A开销决定不能仅用时长假设大小合格。
每片保存 file sha256、byteLength、decoded duration、起止原会话时间、重叠区间和时间映射；不要依赖文件名字串推测来源时间。尾段不能漏；重叠不能导致无限循环。`maxDuration > overlap`，非法值直接拒绝。

## 时间映射 / 回导
M2 保留完整会话时间轴：global_ms = file_local_ms + part.startUs/1000（编码延迟已验证/补偿）。暂停填静音，不能删除时长；每个分片仍保存 spans 和重叠，示例见 export manifest。范围剪辑、删除暂停及其他时间编辑延后；未来若删除区间，必须存 piecewise spans，不能套单一 offset。
外部模型转写的时间戳可能近似；导入不等于验证正确。把近似时间标记为 approximate；无法给时间戳的文本也能导入，但不能伪装精确可点击定位。

## 隐私导出
只导出用户明确所选的混音/分段及需要的清单或通用提示词副本，不把源 mic、原始诊断、浏览器 profile、其他会议/项目、会议 URL 打包；清单不泄露本地用户名/绝对路径。显示完整时间覆盖、内容清单和实际大小，停止录音后可试播，再由用户自己上传。导出请求从不授权上传。

M2 不提供书签附近/手工区间导出、敏感区间编辑或术语管理；延后这些编辑功能不降低文件选择与路径保护要求。后续敏感处理优先做保留时长的静音副本，并明确原音仍保存；任何裁剪都须更新时间映射。
