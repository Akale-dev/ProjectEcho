## M3D：硬件、提示词和多个识别版本（2026-10-01）

左侧点会议 →「转写与搜索」→「本地识别」，选择已准备好的 whisper.cpp 程序和模型。

两个选择按钮旁各有**「如何配置」**，打开内置教学窗并直接进入引擎或模型教程；里面按步骤说明下载、完整解压、选文件和常见问题。英文/繁体界面对应语言，窗口内容可滚动，底部可关闭；只在点击官方链接时打开浏览器，不自动下载。

- **CPU**：兼容默认模式，旧配置继续用 CPU。线程可设置 1–64。
- **自动**：由所选引擎选择设备，允许使用 CPU；尝试记录保留实际后端证据。
- **Vulkan**：可用于有 Vulkan 支持的 AMD / Intel / NVIDIA 环境，必须选择编译了 Vulkan 后端的 `whisper-cli.exe`。M3G 完整包附独立 Vulkan 程序，CPU/Vulkan 选项会切换本包内对应文件；自选包外引擎不会被替换。实际GPU验证以当前报告为准。
- M3H已移除CUDA选项；旧CUDA配置要求重新明确选择硬件。

GPU 编号默认 0，指 whisper.cpp 枚举的设备编号，不是 Windows 设备管理器编号。指定 Vulkan 后，若引擎未报告正确后端或初始化失败，本次任务会明确失败；手动选 CPU 可以重试。保留引擎随带的依赖，不要只替换 EXE。应用不自动下载引擎、驱动或模型。[官方 Vulkan 说明](https://github.com/ggml-org/whisper.cpp/blob/b5130/README.md#vulkan-gpu-support)

**Initial prompt** 可填本场公司名、人名、ticker、行业术语，例如 `Example Corp, EXM, Jane Smith, EBITDA, EPS, free cash flow, 自由现金流`。使用简短准确的术语表；模型有上下文 token 上限，提示词不是强制替换词典，也不保证专有名词正确。最多 4000 字符，仅交给本地进程，输入后自动保存给当前会议；切换会议读取该会内容，默认配置不包含提示词；每次尝试也保留当时提示词。新会议提示词为空，可按本场需要填写。没有联网上传。

换模型或用同一模型重新识别都新增独立原稿；人工校订另存子版本。回听与字幕校订各自有版本下拉框，显示**模型名、完整日期时间、原稿/修订和版本短码**。选择旧版后可回听、校订或导出该版；刷新保留选择。切页/切会议会保留本次运行内的未保存校订草稿，关闭应用前仍须点保存修订。

录音时「新会议录音」旁闪烁红点，暂停显示暂停标识，收尾显示等待状态；它反映程序会话状态，不替代来源和麦克风状态。识别时对应会议右下角闪烁「识别中…」，点击即回该会议本地识别页；普通录音与会后识别并行时也可查看，所有回放仍锁定。M3G 已移除10秒试录入口；需要检查声音时可主动开始普通录音，再自行停止。

模型 SHA-256 输入框及预期值比对已移除，旧配置中的该字段被忽略。音频、识别输入、原稿完整性检查及本地尝试的文件指纹继续保留。验证详情见 [M3D 实施报告](56_M3D_IMPLEMENTATION.md)。

## 会议库

左侧“02 会议库”旁的漏斗按钮打开筛选窗口。可选择起止日期（含当天）、项目、最短/最长分钟数，并按日期、长度、标题或项目排序。留空表示不限；“重置”恢复默认日期倒序。筛选不改变会议文件，也不会删除正在校订但未保存的文字。

每场会议显示日期、标题、项目与长度。尚未完成或元数据需要检查的录音会有标记。新索引使用数据目录中的 `library.sqlite3`；现有会议首次刷新即纳入，不需搬动原件。转写搜索使用每场会议内可重建的 SQLite 索引，支持中文短词和英文。录音与时间索引的事实仍保存在原文件中。

会议右侧“⋮ → 删除会议…”会先要求确认，默认不删除。确认后整场资料移到 `DeletedMeetings/<时间与唯一标识>/<原会议目录名>`，从会议库中移除。录音、导出、转写或恢复尚未完成时不能删除。需要恢复时，先等待文件任务结束，再将最内层的原会议目录完整移回同一数据目录的 `M1Recordings`，然后刷新。若同名目录已存在，不要覆盖。

## 回听、字幕与文字

回听页与“转写与搜索 → 字幕回放与校订”共用一个播放器。进度条采用平滑显示，暂停、拖动、倍速切换后会重新对齐播放器；字幕时间仍是近似值。录音期间，包括暂停与停止保存过程，所有本程序回听入口保持禁用。

回听有字幕时，播放到当前句会自动选中并滚动到可见位置；空隙不选中其他句。暂停、定位和切换字幕版本仍对应当前音频位置，自动选中不会触发重复跳播。

字幕校订页底部固定状态栏，其上固定播放进度和操作栏；只滚动字幕列表。选中一句后可按“复制”或 `Ctrl+C`，复制的内容只有该句文字，不带时间戳。编辑框里 `Ctrl+C` 仍按通常方式复制所选文字。点击字幕或按 `Enter` 可以定位回听。

两处“导出字幕…”旁都有“导出全文…”。全文输出 UTF-8 `.txt`，按所选版本保留所有句子，不带时间轴，也不自动总结、合并重复句或覆盖原稿。无时间的文字稿也可导出全文。字幕导出仍使用 SRT/VTT，保留完整录音时间轴。

“转写与搜索”的顺序是“本地识别 → 字幕回放与校订 → 导入文字”。本地识别可以显示 whisper.cpp 实际回报的百分比；准备、校验、没有百分比回报时使用不确定进度。识别达到 100% 后还须完成保存，看到完成状态才表示新版本已落盘。仍可以取消并重试。

大模型加载和首个音频窗口处理可能较慢。界面分别显示当前阶段、已用时和活动提示；百分比只在引擎回报时更新，反映已处理的音频窗口，不代表总耗时。即使百分比暂时不变，活动提示与计时仍继续；不会用计时器捏造进度。

## 设置与语言

“04 诊断与设置 → 选择数据目录”旁新增“打开数据目录”。它打开当前所选数据根，便于查看录音、导出、索引和可恢复删除区。

主界面左下角`EN/中`按钮可立即切换简体中文、繁體中文和 English，并记住本便携包的选择。01–04与语言按钮左对齐。切换只改变界面模板，不翻译或改写会议标题、项目、字幕、文件路径或音频。系统设备名称与原始技术诊断可能保持来源提供的文字。

## 原件与测试边界

请保留完整便携文件夹。程序正常录音、混音、导出与 SQLite 索引不需要安装 .NET SDK、Python、Node 或数据库服务。可选本地识别仍使用用户明确配置的现有引擎与模型；软件不在开始录音时下载模型，也不自动上传任何资料。

新包的默认数据目录为包内 `Data`。历史会议仍在原位置；在设置选择原数据根即可读取。独立麦克风默认关闭，与 Zoom/Webex 静音互不联动。两小时带麦克风耐久测试的通过范围须查看实际证据，不能直接等同真实会议兼容或双设备声学同步通过。

麦克风启动修复版会在适用设备上选用同一麦克风的 RAW 共享流，避免本机已复现的启动转换短包；预检显示实际模式。RAW流可能不使用Windows软件音效，因此声音与默认处理模式可能不同；程序不会改变系统设备格式或自动换麦克风。实际未收到的音频仍保留缺口提示，旧录音缺失的内容不能补回。

旧版本生成的本程序录音混音需要在“导出音频”主动点击“生成 / 重试完整混音”，再回听或导出；原轨与旧混音均保留。新规则避免把极短的真实麦克风缺口当成时间取整误差。外部导入录音保持原来的完整文件时间轴。
