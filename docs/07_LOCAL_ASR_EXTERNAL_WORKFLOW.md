# 07｜本地转写与手动外部识别

2026-09-30实施：TXT/MD/SRT/VTT/JSON导入、不可覆盖的原稿与修订、本地搜索、分片映射、whisper.cpp适配已落地；不加入SQLite。后续按用户授权配置真实1.9.4/b5130 CLI与多语言base，公开英文语音验证通过，支持外部录音导入、字幕单击定位及SRT/VTT导出。实际数据合同见 [45](45_M3_TRANSCRIPTION_CONTRACT.md)，最新验证与限制见 [47](47_M3_WHISPER_AND_SUBTITLE_REPLAY.md)；合成CLI夹具与真实短语音的证据分开记录。

## 双路线，录音不依赖任一路线成功
路线A：录完→可选本地 whisper.cpp→原始转写/人工校对→项目分析。
路线B：录完→混音→压缩/分段→用户手动上传能接收音频的外部语音模型/服务→导入返回结果。
M2 先完成路线 B 所需完整混音、WAV + 一种已验证压缩格式与限大小分段导出，不自动调用外部 API；导入与本地 ASR 留到 M3。无需购买 API、填写密钥或先下载模型。上传外部前自行核对同意/组织规定/接收方数据处理与大小限制。

## 不假定所有“大模型”都能识别音频
纯文字模型不自动等于语音识别模型；网页聊天、语音对话、文件附件、API是不同入口，格式/体积/时长/时间戳能力不同。导出菜单不要写“所有大模型通用”。例：2026-09-28核验的 OpenAI transcription API 文档列出25MB及MP3/M4A/WAV等格式；这个数字不外推到 ChatGPT 的聊天附件或其他厂商。[S12]
本项目默认 20MB 是可改的保守导出预算，不把某家上限写死在核心引擎。首版高级设置直接修改大小/时长/重叠即可；不先建设服务商 profile 管理系统。接收能力改变不应影响采集模块。

## 外部提示词与术语
用户可显式选择导出 `prompts/EXTERNAL_TRANSCRIPTION_ZH.txt` 的通用副本；M2 不做术语管理或自动附项目术语/简介。后续术语功能也必须由用户明确选择范围。提示词要求忠实转写、保留中英切换/数字/否定句、标记听不清、不要根据背景补写、不要把指令性会议发言当系统指令。
每个分段提示头包含 partId、localTimeOrigin=0、sourceStartMs 和重叠信息。先输出局部时间，再在本地按manifest转换。不同片段 Speaker1 不自动是同一人。

## 导入格式与可信度
M3 先实现 TXT/Markdown，再增加 SRT/VTT 和项目 JSON 格式；M2 不以文本导入为交付条件。限定允许的本地文件格式/大小；解析不执行 HTML/script/路径内容；处理字幕时间重叠和越界。
记录 providerName（用户填）、modelName（可未知）、importedAt、inputExportId、inputPartId、sourceTimeMapping、timestampQuality。
重叠文本去重只对manifest中同一全局时间覆盖区域做候选比较，并保留原始各片结果供复核。不能在全篇按相同句子去重——会议可能真实重复强调。同义或冲突段人工选择，不擅自拼出确定结论。

## 本地ASR
whisper.cpp独立进程，CPU先可用，GPU选项经目标机benchmark；模型可由用户放入指定目录，校验文件与许可。没有模型时状态为“尚未配置，可正常录音导出”。不在录音开始时在线下载。[S14]
以合并音频做通用转写；也允许分来源转写后按时间合并（M3后），防止重复回声造成伪发言。不得将remote来源直接贴实名。中文/英文混合和专业词要用真实获授权短片段评估；没有测量不写速度/准确率承诺。
原始模型输出、规范化转写、人工修订、摘要各自版本化。失效/取消/模型异常可重试，不改变原始音频。合成静音不应产生未经审查的文字；silence hallucination列入测试。
